# Chat Box Spec

## 0) 기본 정보
- 컴포넌트 이름: Chat Box
- 버전: v1
- 적용 범위: 제품의 LLM 대화 화면, 우측 메인 콘텐츠 영역
- 소유: Product Design + Frontend

## 1) 목적/역할
- 사용자 질문과 AI 응답을 대화 흐름으로 제시한다.
- 텍스트 입력과 파일 업로드를 한 영역에서 처리한다.

## 2) 고정 규칙 (Always)
1. 상단 헤더 + 메시지 리스트 + 하단 입력기(composer) 구조 유지
2. 파일 업로드는 `multiple` 허용, 업로드 목록은 입력창 위에 칩으로 노출
3. `Send`는 텍스트/파일 둘 다 비어있으면 비활성
4. 사용자/어시스턴트 메시지는 정렬과 톤이 명확히 구분되어야 함

## 3) 레이아웃/치수
- 기본 폭: `min(920px, 100%)`
- 최소 높이: 520px
- 헤더 높이: 58px
- Composer 높이: 내부 요소 기준 최소 40px
- 메시지 버블 최대 폭: 데스크톱 76%, 모바일 92%

## 4) 상태 (States)
- Default: 대화 가능 상태
- Upload Pending: 파일 칩 노출
- Send Disabled: 입력/첨부 없음
- Focus Visible: 입력창, 버튼 포커스 링 노출
- Error(확장): 업로드 제한/포맷 오류 메시지 영역 추가

## 5) 파일 업로드 규칙
- 지원 예시: PDF, CSV, XLSX, DOCX
- 최대 첨부 개수: 10개
- 중복 파일 처리: 이름/크기/수정시각 기준 dedupe
- 파일 제거: 칩의 `x` 버튼으로 개별 제거

## 6) 접근성 (A11y)
- 파일 리스트: `aria-live="polite"`
- 제거 버튼: 파일명 포함 `aria-label` 제공
- 키보드 조작: 업로드 버튼, 제거 버튼, Send 모두 탭 접근 가능
- 대비 기준: 텍스트/라인 4.5:1 이상 유지

## 7) 금지사항 (Must Not)
1. 파일 첨부 상태를 아이콘만으로 표현하지 않는다(텍스트 병행)
2. 메시지 정렬 규칙(assistant 좌측/user 우측)을 혼용하지 않는다
3. 입력창/업로드를 별도 모달로 분리하지 않는다

## 8) 화면 가이드 연동 규칙
- 화면 Design Guide에서 Chat Box는 공통 컴포넌트로 참조한다.
- 화면별로 조정 가능한 값은 아래만 허용한다:
1. 모델 이름 칩 텍스트
2. placeholder 문구
3. 지원 파일 형식 문구
4. 최대 높이/폭(브레이크포인트 내)

## 9) 변경 관리
- 첨부 정책 변경(개수, 확장자, 크기)은 버전업으로 관리
- 메시지/입력 구조 자체 변경은 v2에서 논의
